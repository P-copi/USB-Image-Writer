# BYD GPack Navigation Probe V0.2.2

ฐานเดิม Phone Space V0.7.4 ไม่แก้ไข / ไม่แก้ GPack ต้นฉบับ

ผลเดิม: ทางเลือก 5 เปิด Maps ได้ แต่ไม่มีจุดหมาย จึงไม่ถือว่าผ่าน

รุ่นนี้ทดลองช่องทาง GPack 8 แบบ (รหัส 8–15) โดยฝังพิกัดและภาพตัวอย่างมาแล้ว ไม่ต้องค้นหารูปหรือเปิดสิทธิ์ระบบ

วิธี: เปิดแอปใหม่ (ชื่อ BYD GPack Navi Test 0.2.2) → กดทดสอบหมายเลข 8 (GPack + navigation URI) → เมื่อ Maps เปิดหรือไม่เปิด ให้กลับมาเลือกผลที่เห็นจริง → ทำถัดไปได้ หรือกดเริ่มชุดทดสอบ 8 แบบโดยรับรองผลทีละแบบ

มีปุ่มปลดล็อกสถานะค้างหากเผลอออกจากแอป ไม่ต้องถอนติดตั้ง

ปุ่มภาพ GPS ที่ฝังในแอปใช้ชุดทดสอบ GPack แทน Android Maps URL ตรง

หากเปิด Maps แต่ไม่มีหมุดและเส้นทาง ให้เลือก 'เปิด Maps แต่ไม่แสดงจุดหมาย/จุดหมายผิด'

ถ่ายรูปหน้ารายงานหรือคัดลอกรายงานส่งกลับ เพื่อค้นหารูปแบบส่งพิกัดที่ใช้ได้จริง

รายงานสถานะ 'Android accepted launch request' เพียงบอกว่า Activity เปิดได้ ไม่ยืนยันว่าพิกัดถูกนำไปใช้

**ข้อควรระวัง:** ทดลองขณะรถจอดสนิทเท่านั้น ไม่มีการควบคุมรถ ไม่มีสิทธิ์ root และไม่แก้ settings ระบบรถ

หมายเหตุ: ใช้ applicationId ใหม่ ทำให้ติดตั้งควบคู่กับรุ่นทดสอบ 0.2.1 ได้ เพื่อเลี่ยงความต่างลายเซ็น debug จาก GitHub Actions
