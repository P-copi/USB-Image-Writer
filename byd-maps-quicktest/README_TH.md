# BYD Maps Bridge QuickTest 0.2.1 (Phone Space V0.7.4)
แอปเสริมเพื่อทดสอบการเปิด Google Maps ด้วยลิงก์ พิกัด รูปภาพ EXIF และ GPack โดยไม่แก้ Phone Space หรือ GPack ตัวเดิม
- กดภาพ GPS ที่ฝังใน APK หรือกดลิงก์สำเร็จรูปได้ทันที
- ตรวจออฟไลน์ในคลิกเดียว: อ่านภาพ GPS, ปฏิเสธภาพไม่มี GPS, สร้าง Maps URLs, รายงานการมองเห็น GPack
- ทดสอบเปิด Maps 8 วิธีแบบมีผู้ยืนยันผลบนจอจริง
- ส่งรายงานผลด้วยปุ่มคัดลอกหรือแชร์
- ไม่มีสิทธิ์ Root, Overlay, GPS สด หรือเข้าไปแก้ค่าระบบรถ
- ภาพ GPS เป็นภาพทดสอบเชิงสัญลักษณ์ ไม่ใช่ภาพถ่ายจริง; พิกัด 13.756331,100.501765 กรุงเทพฯ เพื่อทดสอบเท่านั้น
ข้อสำคัญ: ส่ง Intent สำเร็จไม่แปลว่า Maps ภายใน GPack เปิดจุดหมายจริง ต้องกดรับรองทีละวิธี
การทดสอบควรทำขณะรถจอดสนิทเท่านั้น
