▶ เปิด Google Maps นำทางทันที

หาก Chrome ไม่ยอมเปิดแอปโดยอัตโนมัติ ให้แตะปุ่มสีเขียวเพียงครั้งเดียว วิธีนี้ผ่านการทดสอบกับ Google Maps ใน GPack แล้ว

เปิดแอป Maps ด้วย URI (ทางเลือก) เปิดเส้นทางบนเว็บ (สำรอง) ดูตำแหน่ง GPS ของภาพ

โหมดอัตโนมัติ
