Google Maps นำทาง

รอรับ GPS จากภาพใหม่
▶ เริ่มนำทางทันที

ระบบจะทดลองเปิด Maps เองเมื่อได้รับภาพใหม่ หาก Chrome จำกัดการเปิดแอปอัตโนมัติ ให้แตะปุ่มสีเขียวครั้งเดียว ซึ่งเราได้ทดสอบว่าเข้าโหมดนำทางได้โดยไม่ต้องกด “เริ่ม” ซ้ำ

เปลี่ยนจุดหมายระหว่างนำทาง

เมื่อกลับเข้ามา Web Bridge สามารถเลือกจุดหมายที่เคยส่งจากภาพได้ ไม่ต้องกลับไปเลือกภาพหรือคัดลอกที่อยู่เว็บใหม่

หรือค้นหาจุดหมายใหม่โดยใช้ชื่อสถานที่หรือพิกัด

▶ นำทางไปยังจุดหมายที่ค้นหา

การเลือกจุดหมายใหม่จะเปิด Google Maps ผ่านคำสั่งนำทาง (อาจแทนที่เส้นทางเดิม หรือให้ Maps ยืนยันก่อน)

ทำทางลัด Web Bridge — ไม่ต้องพิมพ์ 127.0.0.1 ซ้ำ

ครั้งเดียวใน Chrome ภายใน GPack: เมื่อเปิด http://127.0.0.1:8774 แล้ว ให้กดเมนู ⋮ → เพิ่มบุ๊กมาร์ก (รูปดาว) หรือ “Add to Home screen / Create shortcut” หากเมนูนี้มีให้ใช้

ตั้งชื่อว่า “BYD นำทางจากภาพ” เมื่อกลับจาก Maps ให้เปิด Chrome → เลือกบุ๊กมาร์ก หรือแตะทางลัดที่สร้างไว้ แทนการพิมพ์ URL

วิธีสร้างทางลัดขึ้นอยู่กับเวอร์ชัน Chrome/GPack; ถ้าไม่รองรับให้ใช้บุ๊กมาร์กแทน การสร้างทางลัดไม่ได้ทำให้ Android หลักเปิด Chrome ภายใน GPack ได้เอง

ตรวจเสียง Google Maps / ลำโพงรถ

ทดสอบขณะรถจอดสนิทเท่านั้น • การทดสอบนี้ไม่เปลี่ยนการตั้งค่า Google Maps หรือระบบรถ

ยังไม่ได้ทดสอบ

หากไม่มีเสียงสัญญาณจาก Chrome ให้ตรวจระดับเสียงสื่อ (Media) และช่องทางออกเสียงของ GPack ก่อน

ตรวจเสียงจริงของ Google Maps:

เปิดแอป Google Maps ภายใน GPack → แตะรูปโปรไฟล์ → การตั้งค่า → การตั้งค่าการนำทาง (Navigation settings) → เล่นเสียงทดสอบ (Play test sound) จากนั้นเลือก ระดับเสียงนำทาง: ดังมาก (Louder) หากเสียงเบา

ถ้าระบบเสียงไม่ตรงลำโพง ให้ตรวจตัวเลือก เล่นเสียงผ่าน Bluetooth (Play voice over Bluetooth) ให้เหมาะกับการเชื่อมต่อจริง หากไม่มีคำสั่งเลี้ยวขณะรถจอด Maps อาจยังไม่พูด ซึ่งไม่ใช่หลักฐานว่าระบบเสียงเสีย

ผลที่ได้ยิน:

แสดงภาพและเครื่องมือตรวจสอบ (ไม่จำเป็นต่อการนำทาง)

ภาพย่อจากรูปที่ยืนยันแล้ว เก็บไว้ตรวจสอบเท่านั้น

ภาพไม่ได้ส่งขึ้นอินเทอร์เน็ต มีเพียงพิกัดสำหรับนำทางเท่านั้น

เปิด Maps ด้วย google.navigation (สำรอง) เปิดเส้นทาง Google Maps บนเว็บ (สำรอง) ดูหมุด GPS ของภาพ
